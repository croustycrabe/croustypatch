# CroustyLab design system

This folder is the project's design system. Before building or changing any UI:

1. Read `README.md` here for the rules (colour, type, borders, shadows, the press effect, tone of voice).
2. Use the values in `tokens.json` / `tokens.css` by name. Never hard-code a colour, size, radius or shadow that a token covers.
3. For a component, read `components/<Name>/README.md`, and copy its markup from `components/<Name>/preview.html` and its styles from `components/bundle.css`.
4. Logos, icons and illustrations are in `assets/`. Use these files; never redraw the crab logo.
