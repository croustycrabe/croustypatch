# Brand icons

`../brand-icons.json` holds a curated subset of [Simple Icons](https://simpleicons.org) (CC0 1.0 Universal, public
domain): per icon its title, official colour and SVG path. The app catalog refers to one as `brand:<slug>`.
The trademarks themselves belong to their owners; the icons only identify the application.

Regenerate with `generate.py` (see its header). Add a slug to `SLUGS` to bundle another icon.
